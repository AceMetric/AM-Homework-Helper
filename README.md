# DDL-Manager

原生 macOS 截止时间管理器，支持日历、任务编辑、本机提醒和任务备份。本分支在 [原作者的 DDL-Manager](https://github.com/123456p-df/DDL-Manager) 基础上增加 GitHub 课程作业管理和应用内更新功能。

适用于 **macOS 13+、Apple 芯片**。

## 功能

- 管理“老师截止时间”和“我的 DDL”，使用日历、菜单栏及系统提醒。
- 常驻侧栏统一“总览、日历、任务、待审核作业、课程”；浅色和深色自动跟随 macOS，使用统一的蓝色强调与原生弹窗、菜单。
- 从老师仓库当前默认分支的 Markdown、纯文本等文档发现作业；启动时、每 6 小时及手动检查。
- 显示原文、文件位置和附近任务说明，审核后才加入任务；老师更新原文时提供更新建议。
- 识别中文完整日期、星期附注与时区；日期缺少时间时要求补全。相对日期按截止语句的上游提交时间给出建议，确认后才导入。
- 区分作业、课上任务和考试。考试题目归属同一次考试，只在课程页标注；支持类型筛选与人工修正。
- 关联本地课程仓库，合并老师上游、处理冲突、逐项选择文件提交。
- 应用内检查新版本、查看更新说明、确认下载与重启；未保存内容和正在执行的作业操作受到退出保护。
- **作业只推送到经核验属于当前登录用户的个人 fork，绝不推送到老师仓库，也不强推。**

## 安装与使用

此开发分支尚未发布 GitHub Release。维护者可通过发布脚本生成测试包；包名为 `DDL-Manager-1.1-macOS-arm64-candidate.zip`。当前构建使用临时签名，**未经 Apple 公证**。

解压后将 `DDL-Manager.app` 放入“应用程序”。首次打开若被系统阻止，可在“系统设置 → 隐私与安全性”按系统提示选择“仍要打开”。更新前退出正在运行的旧测试版。

### 软件更新

从应用菜单选择“检查更新…”，或在“设置 → 软件更新”管理自动检查。带更新功能的版本首次仍需手动安装；此后更新会等待课程操作结束，并提示处理未保存内容。当前正式更新源尚未发布，不影响本机任务使用。[完整更新说明](docs/UPDATES.md)。

### 日历与提醒

打开应用后进入“今日与近期安排”，按逾期、今天和未来七天查看未完成任务。“日历”支持连续月份、月份跳转、定位今天及选中日期的任务；窄窗口会把当天任务移到日历下方。“任务”中可筛选已完成、归档和最近删除。

点击“新建任务”填写任务、截止时间和提醒；也可粘贴公告或识别截图。老师截止时间与“我的 DDL”分别保留，可设置提前天数。所有任务使用同一编辑弹窗，长内容可滚动，日期选择器按需展开；Return 保存、Escape 取消，备注内需要换行时使用 Shift-Return。外观自动跟随电脑，不需要选择配色。

通知权限在侧栏“设置 → 提醒设置”中管理，可用“提醒测试”检查。关闭主窗口后应用继续在菜单栏运行；退出应用、关机或休眠期间无法定时扫描。

原版用户可先导出任务备份，再在本版“任务 → 导入任务备份…”导入。备份可能包含任务备注和来源，分享前请检查个人信息。

### GitHub 课程作业

1. 在侧栏打开“课程”，点击“连接 GitHub”。先在“安装授权…”中只授权自己的课程 fork，再设备码登录。已有账户可直接“添加课程”。
2. 选择个人课程 fork，按引导关联已有本地文件夹，或选择保存位置下载仓库。私有老师仓库需要本机已配置的 Git 读取权限。
3. 点击“检查作业”。所有课程的新作业与更新建议集中在“待审核作业”，可按课程、关键词及导入状态筛选。
4. 选择一项查看老师原文，打开审核弹窗，核对老师截止时间与“我的 DDL”后确认保存。“本周日”等相对日期会显示基于截止语句提交时间的建议及依据；点击“采用建议日期”或手填完整日期。历史不足或“周末”等含糊写法仍须手填，不能按扫描当天猜测日期。仅有日期时先显示已识别日期，补全时间后才能保存。更新不会直接覆盖手动修改的任务。
5. “更新作业”会获取并合并老师更新，再安全推送到自己的 fork；有本地修改或分歧时会暂停。冲突显示继续入口，失败后在该课程查看原因。
6. “提交作业”显示个人 fork 与目标分支；文件默认不勾选，可先查看变更，再逐项选择并填写提交说明。敏感文件不可提交，推送前仍会检查完整提交范围。推送失败时保留本地提交，修复原因后使用“重试推送”。

“更多”提供课程关联、自动检查、仓库与操作详情、移除等操作。当前操作显示阶段并锁定写操作，浏览其他页面或课程不会改变正在执行的目标。侧栏账户入口可取消尚未完成的设备登录；Git 写操作不提供中途取消。

“课程 → 课程内容”可按作业、课上任务、考试或待确认类型筛选，并查看原文。考试与课上任务不会进入待审核作业、日历或提醒。识别有误时选择内容后点“更改类型…”，修正保存在本机并用于后续检查；已有任务不会被自动删除。明确的作业即使未说明截止时间，也会进入审核；教材示例、目录链接和作业中的普通日期叙述不会作为截止要求。

快捷键：⌘1 总览、⌘2 日历、⌘3 任务、⌘4 待审核作业、⌘G 课程、⌘N 新建、⌘F 搜索当前页面。

已预置 [GitHub App 安装入口](https://github.com/apps/ss-homework-manager/installations/new)。这个 App 沿用注册时的名称 **SS Homework Manager**，与桌面应用的显示名称不同；使用预配置的测试包无需自行注册。若上游采用自己的 GitHub App，维护者可按 [配置说明](docs/GITHUB_APP_SETUP.md)替换两项公开信息。

## 数据与安全

GitHub 访问令牌和刷新令牌只保存在本机钥匙串，不进入仓库、日志或任务备份。应用不附带私钥或 Client Secret，不更改全局 Git 配置。

本次恢复显示名称时保留旧测试版的内部标识与数据位置，已有任务、课程关联及登录信息可继续使用：

- Bundle ID：`io.github.acemetric.sshomeworkmanager`。
- 数据目录：`~/Library/Application Support/SS Homework Manager/`。

该目录与原版 DDL Manager 独立；原版任务仍通过备份导入。详细推送校验、凭据处理和提交限制见 [安全说明](docs/SECURITY.md)。

## 识别范围与验证状态

当前使用本地规则扫描文本文档，支持 Markdown、纯文本、RST、AsciiDoc、Org 和 TeX；不解析 PDF / Office 附件。附件作业可从正文中的说明发现，但不会自动读取附件内容。单文件最多 1 MB，单次文档总量最多 30 MB。

构建、模拟 GitHub API、临时 Git 仓库及 AppKit 回归已验证。真实账户设备登录、私有课堂仓库操作和通知送达仍需在实际使用环境中核对。完整记录见 [验证状态](docs/VERIFICATION.md)。

## 开发与贡献

需要 macOS Command Line Tools 和系统 Python 3；首次构建会下载并校验固定版本的 Sparkle：

```sh
zsh build.sh
zsh test.sh
zsh verify-homework.sh
```

构建产物为 `build/DDL-Manager.app`。模块说明、完整验证命令、打包流程和上游 PR 注意事项见 [开发与贡献](docs/CONTRIBUTING.md)。

来源与署名见 [原作者与授权记录](docs/ATTRIBUTION.md)；原版用户指南保存在 [原版说明](docs/UPSTREAM_README.md)。
