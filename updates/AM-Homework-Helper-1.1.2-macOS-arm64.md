# AM's Homework Helper 1.1.2

首个公开版本，适用于 macOS 13+、Apple 芯片。

- 启用应用内在线更新：默认每天检查，由你确认下载、安装和重新打开。
- 软件名称为 AM's Homework Helper，仓库更名为 AM-Homework-Helper。
- 支持老师上游作业发现、日期建议、作业 / 课堂任务 / 考试分类，以及连续审核。
- 更新会等待课程操作结束，并检查未保存输入；作业仍只推送到经核验的个人 fork。

## 安装与兼容

**本版使用临时签名，未经 Apple 公证。** 更新来源签名不等同于 Apple 公证。

1.1 / 1.1.1 测试版需要从 GitHub Releases 手动安装本版一次，替换旧应用；旧更新地址不再使用。任务、课程绑定和登录信息继续沿用。新版此后通过应用内更新，无需登录 GitHub。

退出旧应用，解压后把 AM's Homework Helper.app 拖入“应用程序”。首次打开如果 macOS 阻止，请在“系统设置 → 隐私与安全性”按系统提示选择“仍要打开”。不要同时运行旧版与新版。
