# AM's Homework Helper 1.3.5

- 课程页选中作业后直接在侧边填写、确认，不再弹出审核窗口。修复审核按钮点击无响应。
- 保存成功立即离开默认待审核列表；全部结果及课程内容明确标记已审核，可直接保存修改，重复保存不复制任务。
- 任务、总览和日历直接显示自己的备注，支持在列表内展开全文；课程的已加入任务也能直接查看和修改。
- 课程页与待审核页共用表单，保留自动预填日期、统一作业 DDL、五档常用提醒及未保存保护。

支持 macOS 13+、Apple 芯片。未经 Apple 公证。已有任务、课程与登录信息保留。
