# AM's Homework Helper 1.3.2

## 更简单的首次使用

- 内置 GitHub 官方登录工具：浏览器登录即可连接已有权限的课程，无需安装命令行工具、配置 SSH 或安装本项目 GitHub App。
- 四步引导：连接账号、选择多门课程、批量关联或下载文件、首次检查。可返回、取消和下次继续。
- 逐课展示结果和失败原因；首次使用提示可跳过，侧栏“开始使用”可重新查看。
- 已有课程、任务和目录继续使用；切换认证方式需明确选择。

## 安全与兼容

- 登录凭据仅保存在本机钥匙串，禁止明文配置回退，并保护已有官方 CLI 登录。
- 官方登录权限较宽，应用只处理所选课程；仍需本人登录、双重验证和必要的学校 SSO，以及已有仓库访问权限。
- 保留个人 fork 身份核验、敏感内容检查及禁止推送老师仓库的约束。
- macOS 13+、Apple 芯片；主应用未经 Apple 公证。更新签名不等同于 Apple 公证。

已有 1.1.2 或更新正式版本可通过应用菜单“检查更新…”安装。其他测试版本请退出旧版后，手动安装完整应用一次。
