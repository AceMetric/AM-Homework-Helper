# AM's Homework Helper 1.6.0

## 新功能

- **提交记录**：区分本地提交、待推送、待核验和已确认推送；回查个人仓库、分支、提交号及实际文件。支持关联多项作业，失败重试复用原提交。同步与合并单独标记，提交不会自动完成作业。
- **快速录入普通作业**：无需 GitHub 登录，按 ⌘⇧N 输入通知、粘贴文字或选择截图，在本机提取多项作业；全选后核对并保存。完整截止时间自动填写，缺少时间不再假定 23:59，未完成内容保留草稿。
- **通知交给助手识别**：复用共用 Skill 和自动接回。只导出选中的文字与日期依据，不附带任务库、账户或课程仓库；保护手动修改，迟到和重复结果不会再次加入已保存作业。

## 可靠性与体验

- 任务备份同时保存本机提交记录，继续读取旧版任务数组；恢复只处理数据，不执行 Git。
- 保存失败保留草稿和批次，修复共享审核保存后快速录入窗口残留条目的问题。
- 每份通知独立保留参考日期与时区，任务及备份也能保留日期依据，避免多份草稿共存时显示最新通知的日期。
- 修复虚拟任务列表在屏幕外选择和滚动重建后的键盘焦点丢失；调整提交窗口的作业关联与文件区域，避免重叠。
- 备注可编辑或清空，原文独立保留；任务列表保持紧凑，选中后查看完整备注。

## 使用与安全

macOS 13+，Apple 芯片；版本 1.6.0，构建 17。应用未经 Apple 公证，更新来源签名不等同于 Apple 公证。

保留原有任务、课程、计划、子任务、登录与更新密钥兼容。推送始终重新核验个人 fork、明确分支与敏感内容，禁止推送老师仓库或强推。数据与提交记录仅保存在本机，不自动上传诊断或发送材料给助手。

从菜单“检查更新…”安装，或下载 Release ZIP 后退出旧版并替换“应用程序”中的应用。正式环境的下载安装与重启请自行核验；macOS 13 实机、实际通知送达及同学可用性测试仍待验证。
