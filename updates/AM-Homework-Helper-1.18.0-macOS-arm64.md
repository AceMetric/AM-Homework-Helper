# AM Helper 1.18.0

构建 48 · 2026-11-08

- 课程首页合并待审核与已保存作业。可按状态筛选，保存后留在同一份作业，窄窗口分步打开详情。
- 直接提交先核对所选文件的安全与版本。报告和模型检查可主动打开，普通质量建议不再要求额外勾选。待核验或待推送的记录可在对应作业中继续处理。
- 作业详情可打开已获取的远端评语。显示原始提交作者及版本，作者身份不明时标为待核对。新评语按内容版本记录已读。
- 同学作业支持从当前作业进入，也可搜索历史作业。先读取所选作业目录与正文，作答比较继续后台处理。
- 评分入口直接可见，支持读取老师材料中的分值表并保留实际满分。评分生成继续确认材料、模型和请求上限。
- 自动子任务只保留有原文依据的独立交付项。可清理旧自动拆分，保留改过、完成或已安排的步骤。
- 干净分支可自动快进更新本地课程文件。遇到修改、分歧或未完成的 Git 操作时保留原内容并提示处理。
- 启动后的课程检查逐门开始。连接失败时暂停剩余检查和自动提交核验，稍后再试。手动操作仍可使用。
- HTTPS Git 操作跟随 macOS 已配置的 HTTP 代理及例外规则。
