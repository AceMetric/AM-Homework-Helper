# AM's Homework Helper 1.4.0

## 助手识别更省步骤

- 多门课程一次交给助手，使用固定本机批次目录，无需每次选择导出位置。
- 助手完成结果后自动核验并接回待审核；支持进度、部分结果、重启恢复及重试，保留手动导入兼容入口。
- 复用最近检查的材料快照，只核验返回结果涉及的课程和文件，减少重复读取；没有变化时无需再分析。
- 自动接回需要可读写本机材料目录的助手，例如本机 Codex。应用不会自动发送课程原文或调用付费分析，作业仍需审核。

## 作业内容保存后可见

- 新作业备注预填内容概括和提交要求，可修改或清空；不复制老师整篇原文。
- 单项与批量审核使用相同逻辑；已有备注及用户修改受到保护。
- 总览、任务、日历和已加入任务的详情显示完整备注，列表保持紧凑；历史空备注可先预览再补全。

## 统一原生界面

- 共享浅深色、卡片、按钮和输入框样式，精简课程工具栏与审核信息。
- 窄窗口将详情移到列表下方；设置突出规则检查与 Skill，本地模型、云 API 收入高级设置，保留已有配置。
- 保留全选、批量确认和侧边审核，保存成功移除条目，失败保留输入。

## 兼容与验证

支持 macOS 13+、Apple 芯片。保留原任务、课程绑定、登录与更新签名，以及仅向个人 fork 推送的安全约束。

发布回归通过 1,119 项原生断言、19 项 Python 测试、5 项运行器断言，另完成 62 项课程副本使用断言和 35 项模拟前台操作断言。源码、历史和发布附件隐私扫描通过。正式更新下载安装与重启由使用者验证。

**未经 Apple 公证**，使用临时签名。下载 ZIP 后退出旧版，解压并放入“应用程序”；安装说明与校验文件为独立附件。
