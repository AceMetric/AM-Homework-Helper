# AM’s Homework Helper 1.8.1

## 修复与改进

- 修复 HTML 标签、公式、文件路径、单位和缩写的英文拼写误报；英文拼写建议与语法错误明确区分，重复词语定位到实际行。
- 材料预览改为可调整大小的逐文件阅读器，文档优先；支持排除无关文件、调整顺序、图片放大和滚动。CSV 预览标明截取范围，导出时保留完整选定数据。
- 默认使用附件包交给网页或聊天助手；返回 JSON 后在检查报告导入。能访问本机文件的助手继续支持自动接回。
- 检查报告显示简明覆盖计数，可查看完整范围；切换问题后详情回到顶部。
- 附件包仅含确认的材料，图片副本去元数据；导入核验批次、版本和原文证据，不自动提交或修改答案。

支持 macOS 13+、Apple 芯片。当前构建使用临时签名，未经 Apple 公证。课程、任务、钥匙串与更新密钥保持兼容。

助手的文件和图片能力取决于所使用的服务；不支持 ZIP 时请解压后上传其中的文件。语义和数学复核仍为建议，不能保证答案正确。
