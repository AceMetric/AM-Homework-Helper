# AM's Homework Helper 1.3.0

适用于 macOS 13+、Apple 芯片，构建号 6。**本版未经 Apple 公证。**

- 课程展开在主侧栏，取消课程下拉选择；课程内容采用原生列表与详情，窄窗口自动上下排列。
- 明确区分“检查新作业”和“同步课程文件”；所有课程汇总检查状态，同步与提交只针对具体个人 fork。
- 多课程助手材料包：一次导出、一次分析、一次导入；默认增量，只在有效结果成功导入后推进进度。
- 本地 Ollama 可检测已安装模型、测试识别；支持自动分析和按文件手动重识别，规则结果先显示，失败时仍可使用。
- 改进按钮、状态、空页面与逐课筛选保存，保留任务、课程、提醒与登录兼容。

默认免费规则，模型增强仍初始关闭。助手材料包只保存在本机，选择托管助手会由该服务处理提供给它的原文。API 密钥仍仅存钥匙串，个人任务库及 Git 凭据不进入材料包。

已有 1.1.2 / 1.2.0 可通过应用菜单“检查更新…”安装。更新签名不等同于 Apple 公证。首次安装请将解压后的应用拖入“应用程序”。
