AM's Homework Helper

AceMetric 的原生 macOS 作业助手。管理截止时间、发现 GitHub 课程作业，侧栏直接选课，提取作业名称、内容和截止日期，支持批量助手材料包、原生审核与安全自动加入。

macOS 13+ · Apple 芯片 · 1.15.0

未经 Apple 公证。本版使用临时签名；更新来源签名不等同于 Apple 公证。退出旧版，解压后将应用放入“应用程序”。

1.15.0 支持无仓库课程与统一课程选择、周期任务批量修改、大项子任务。识别减少误报并按原始行号分片核验；倒计时显示更细，总览加入更远期任务。保留已有任务和登录信息，备份继续兼容旧版。

1.14.5 修复本地增强识别的60秒提前中断，初次分析与纠正共用有界总时限，仍可随时停止。练习按独立作业分组，原文依据保持逐字核验，活动直接显示超时或核验原因。

1.14.4 理顺课程检查、同步与提交：模型等待不阻塞文件选择；错误提供对应恢复入口，已有提交先核验再重试，避免重复推送。网络只读请求最多自动重试一次，取消和输出收尾有明确时间边界。

1.14.3 精简活动浮窗与课程操作：运行中只保留停止，结束后可关闭记录；长文字自然换行，刷新保留滚动位置。检查结果显示短摘要，完整统计与失败原因移入详情。

1.14.2 修复升级后旧版提醒残留：清理历史通知身份的队列，固定后续版本的提醒身份，再按最新任务状态安排提醒。维护过程不修改任务、课程或登录信息。

1.14.1 修复已完成作业残留提醒，并在退出与更新前确认提醒清理；修复识别核验与部分结果保留，优化课程、通知和项目复核提示词。本地核验失败最多纠正一次，云端不自动补发；活动面板集中显示失败项并支持查看原文与重试，登录设置按钮改为竖排。已有任务与登录信息继续沿用。

1.14.0 统一新建、编辑与审核表单，后台状态集中到“活动”。检查报告采用单一预览，图片问题支持红框批注；修复公式重复、错误图片复用及提交读取本地变更时等待后台历史查询的问题。任务、课程与登录信息继续沿用。

1.13.3 让任务编辑随窗口适配，周期任务列表只显示未来最近两次。核验个人远端提交后可自动完成对应作业；修复已完成任务仍提醒。检查报告支持 Markdown，提交各步骤可终止并核验重试，文件刷新保留草稿；修复日历切换和更新退出问题。

1.13.2 只分析新增与变化的课程材料，减少重复等待；待审核建议可删除、撤销与恢复。修复未修改也提示保存的问题，模型运行时可继续浏览和编辑，新操作可排队。统一原生工具栏切换，修复日历周末与假日底色及任务条显示。已有任务、课程和登录信息继续沿用。

1.13.1 修复课程检查的进度条与取消按钮重叠，按原生控件尺寸及外边距布局；窄窗口、长状态文字与恢复操作同时显示时保持分离。检查结束后收起进度条和取消按钮。已有任务、课程和登录信息继续沿用。

1.13.0 新增周期任务、中国大陆周末及2026年假期调休、本机学校安排覆盖，以及终端 Git 提交自动发现。修复输入与备注圆角、窗口底部操作和点击灰色区域退出；日历任务对齐，设置选项直接显示，其他折叠标题整行可点击。课程 AI 增强由用户主动确认材料，复核继续保留整份项目上下文；真实模型质量与旧系统实际外观仍有验证范围限制。

1.12.2 修复日历“今天”后退、移除主窗口重复进度区；设置关闭入口固定顶部并支持点击应用中的外部区域。升级时不自动重开已有配置。提交前本机检查与后台课程扫描分离，确认当前输入并完整显示状态与错误提示；对方设备原始点击故障尚未独立复现，保留实测限制。

1.12.1 将任务名称、课程、日期、时间、提醒、提交说明及密钥输入统一为系统圆角样式；macOS26+使用公开胶囊边框，旧系统使用原生圆角边框。保留系统焦点、键盘编辑及浅深外观。

1.12.0 将已确认的原生控件推广到总览、任务、审核、设置及引导：系统侧栏与工具栏、直接快速录入、可退出并保留内容的搜索、原生分段选中态。提交与检查报告可拖动分栏，展开预览支持完整阅读和复制；运行中显示进度，后台记录从“窗口”菜单查看。macOS26+使用系统 Liquid Glass，正文保留清晰底色，旧系统使用标准原生控件。

1.11.0 将文件检查移到独立可调整窗口：文件树、Markdown／公式与源码预览、图片缩放，范围说明和排除项收起。离线MathJax分别报告解析错误、兼容疑点及未完成渲染；进度更明显。外观只刷新样式，macOS26+导航采用原生Liquid Glass，旧系统保留原生回退。

1.10.1 增加真实合成生成测试、同一Google服务手动模型选择、可取消的有限重试、图片上传复用及可见后台进度。实际合成文本与图片生成通过，不能保证服务不再503或答案一定正确。

1.10.0 提升免费规则识别：按活动和表格行组织材料，支持无日期英文作业、英文月份和 AM／PM，缺失或含糊的截止时间留待审核。快速录入自动显示候选，保护手动修改；所有课程汇总可直接查看结果。共享原生控件和浅深颜色，报告操作更紧凑。

“检查作业文件…”支持选择文件夹或具体文件，先确认范围再检查本机文档与图片。可选 Gemini 在线复核需自行配置密钥并主动确认发送；相同范围可以复用，变化后重新预览。真实账户故障和模型质量仍需使用者核对，本机检查不保证答案正确。Skill 保留本机自动接回和网页附件两种方式。

首次欢迎页可选“先使用本机作业功能”。普通作业：点击工具栏“＋”或按 ⌘N 新建任务；从文字或截图录入使用 ⌘⇧N，任务详情可选“检查作业文件…”。GitHub 课程：通过内置 GitHub 官方工具在浏览器登录，勾选课程，批量关联或下载文件，一次确认匹配目录即可关联并开始检查，未完成课程可单独重试。无需 SSH 或安装本项目 GitHub App；仍需已有课程权限及必要的 SSO。关闭引导会保留进度，后台完成不会重新弹窗；侧栏“开始使用”提供应用内帮助及继续配置入口。

默认免费规则。点击“助手识别”，复制指令给可读写本机目录的助手（例如本机 Codex），完成后自动接回；应用不会自动发送材料或发起付费分析。网页助手仍可手动导入。本地模型、云 API 在设置中直接显示并保留原配置，密钥留在钥匙串。
