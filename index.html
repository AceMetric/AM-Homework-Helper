AM's Homework Helper

AceMetric 的原生 macOS 作业助手。管理截止时间、发现 GitHub 课程作业，侧栏直接选课，提取作业名称、内容和截止日期，支持批量助手材料包、原生审核与安全自动加入。

macOS 13+ · Apple 芯片 · 1.7.2

下载安装包

未经 Apple 公证。本版使用临时签名；更新来源签名不等同于 Apple 公证。退出旧版，解压后将应用放入“应用程序”。

1.7.2 修复后台自动扫描拦住“检查作业”的问题。只读检查与老师扫描、模型分析独立执行，留在当前任务页面，选完文件直接开始并显示报告，已完成任务也能复查。Git写入、已有编辑窗口及退出／更新准备仍受保护，并显示具体原因。检查不会提交或推送，可选择共用Skill复核答案与手写内容。

普通作业：打开“新建 → 快速录入作业…”或按 ⌘⇧N。GitHub 课程：通过内置 GitHub 官方工具在浏览器登录，勾选课程，批量关联或下载文件，再检查新作业。无需 SSH 或安装本项目 GitHub App；仍需已有课程权限及必要的 SSO。可随时返回侧栏“开始使用”查看引导。

默认免费规则。点击“助手识别”，复制指令给可读写本机目录的助手（例如本机 Codex），完成后自动接回；应用不会自动发送材料或发起付费分析。网页助手仍可手动导入。本地模型、云 API 收入高级设置并保留原配置，密钥留在钥匙串。

1.1.2 可直接在应用内更新。1.1 / 1.1.1 测试版需要手动安装本版一次，此后在应用菜单选择“检查更新…”。在线检查和下载无需登录 GitHub，由你确认安装。
