# 检查报告与提交终止回归（1.13.3／35）

## 本轮变化

- 未选择发送与实际检查未覆盖分开；同一路径的重复提示合并，旧报告兼容。
- 疑点详情和完整报告使用本机 Markdown 查看器；原文证据独立围栏，支持源码模式。在线结果仍验证 JSON 结构、来源版本、行号与证据。
- Git 历史检查通过两次批量读取完成，保留完整对象、文件名与敏感内容检查。
- 课程读写步骤、变更预览及在线请求支持终止，命令包含超时；退出资源在实际工作结束后才释放。
- 中断后的本地提交与不确定推送保留记录，重新核验及重试使用同一提交；外部暂存文件不被恢复流程覆盖。
- 失败恢复可重新检查，失效文件选择可刷新；明确取消草稿后不会重复阻止退出。
