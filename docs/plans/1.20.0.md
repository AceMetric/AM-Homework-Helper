# AM Helper 1.20.0 / build 52

## Approved implementation

- Retain immutable native table snapshots; validate stale callbacks and isolate hidden legacy tables.
- Native toolbar back/file navigation, compact assignment identity, adaptive file/preview/inspector layout.
- System Liquid Glass controls grouped by function; remove full-width decorative glass backings.
- Embed selection, commit description and submission in the inspector using the existing safety and Git transaction implementation.
- Isolate drafts by course, repository, branch and assignment. Preserve edits across refresh and navigation.
- LLM-derived actionable requirements with teacher-source evidence; local file checks do not present an unreviewed semantic checklist as content review.

## ChatGPT plan integration (approved addition)

- Use the official Sign in with ChatGPT flow for open-source local apps, not desktop session-file reuse or private service endpoints.
- Independent browser authorization with state, nonce, PKCE and loopback callback; validate issuer, signature, audience, expiry, nonce and granted scopes before activation.
- Save credentials in Keychain, isolated by registration and workspace. Serialize refresh, support disconnect and account changes, and keep credentials out of logs and backups.
- Discover current account models and capabilities. Default to GPT-6 Luna / low for recognition and GPT-6.1 Terra / medium for content review; verify account availability; never treat a bundled model catalog as proof of entitlement.
- Default rolling-hour cap: 60 inference requests; two concurrent requests. Recognition, requirement extraction, review and retries share the cap. Do not reset the ledger on restart or switch accounts to evade limits.
- Cache versioned successful results and avoid duplicate material. Prefer a combined semantic extraction/review request when its result and source references can be validated.
- Explicit material consent before sending answer text or images. Ordinary browsing and unauthorized course refresh make no model requests.
- Use public Responses with store:false, stream:true, supported model inputs, and successful completion events. Partial text is not a completed result. Do not execute tools or shell commands for recognition/review.
- Preserve existing provider settings as alternatives; no silent paid fallback or automatic model substitution. First login is the user's browser action, not an unattended agent action.
