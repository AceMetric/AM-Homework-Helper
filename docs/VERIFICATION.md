## 隐私检查的边界

原 Git 历史有 9 个带既有贡献者邮箱的提交对象；作为原作者来源记录保留。检查输出只统计这类元数据，不打印邮箱或凭据。不擅自重写上游历史。

规则扫描和 OCR 未检出匹配的秘密，不代表能识别任意未知格式的秘密或所有个人信息。公开前仍需维护者检查新增材料，保留原作者公开发行许可的依据。此次没有撤销或轮换现有凭据，没有改变个人 Git / SSH 配置；新生成的更新私钥仅保存在本机钥匙串。
