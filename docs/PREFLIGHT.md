# 提交前检查

1. 在课程中点“提交作业”，逐项选择文件、关联作业并填写提交说明。
2. 点“下一步：检查”。应用检查拟提交版本：当前 HEAD 加上本次所选变更，不把未选文件当成已提交。
3. 查看问题、依据和建议。修改文件后点“重新检查”；新增图片需要返回文件页自行选择。
4. 可选“交给助手复核…”，预览文本、题目和图片，排除图片或调整顺序。复制指令给助手后，结果自动接回本报告。
5. 核对问题与未检查范围，勾选确认，再明确点击“提交到个人仓库”。文件变化会要求复查。

## 只检查已写好的作业

1. 在总览、任务或日历选中作业，点详情栏的“检查作业文件…”。
2. 默认选择整个作业文件夹（含子文件夹），也可选择多个文件。有关联课程时从课程目录开始选择，但不要求 GitHub 登录或 Git 仓库。
3. 在“文件范围”预览中搜索、全选或排除文件；隐藏配置、依赖、缓存、构建目录、符号链接及敏感文件列明原因。核对数量后点“开始检查”。
4. 报告显示本机检查覆盖与问题；可“调整范围”回到原有选择。需要核对答案、推导或手写内容时，点“交给助手复核…”预览范围并复制指令，结果自动接回。
5. 点“完成”关闭报告。不创建提交、不推送、不执行代码，也不改变提交窗口的文件勾选。

| 入口 | 检查的版本 |
| --- | --- |
| 独立“检查作业文件…” | 当前本机文件，包括未提交的修改及当前引用图片 |
| 提交窗口的“下一步：检查” | 当前 HEAD 加上本次选定变更；未选中的已跟踪图片使用 HEAD 版本 |

“检查新作业”是发现老师发布的任务；“检查作业文件…”是检查自己写好的文件。后台读取老师内容不阻止文件检查；Git 写入或退出／更新准备期间会说明暂不可用的原因。已完成任务也可复查。

所选文件夹是读取边界，不读取越界或符号链接目标。越界图片请重新选择共同父目录；远程图片不联网获取。Markdown 引用的图片自动关联、去重；主动排除的图片保持未检查。直接选择文件时以所选文件的共同父目录作为边界，不递归扫描其他文件。

每批最多256个文件（包括引用图片），目录整理最多10,000项。超限要求减少范围，不生成不完整的成功报告。文件在读取时变化会要求复查；报告打开后修改文件会标为过期，重新检查复用未变内容的本机分析缓存。

## 本机能检查什么

- 文本读取、空文件、明显占位、未完成清单、合并冲突标记及疑似未闭合的 Markdown 代码围栏。
- 内联、引用式、HTML 图片，支持中文、空格和相对路径。仓库外路径和符号链接不读取；远程图片不联网获取，标为未验证。
- 图片能否解码、Notebook JSON 的基本结构。Python 在存在 Apple Command Line Tools 解析器时只解析语法；缺少工具或超出限制明确显示未检查，不要求安装。
- 系统英文拼写建议，跳过代码、公式和链接。中文语义、计算、推导、程序运行与答案正确性不算本机检查通过。

每文件上限5 MB，每批读取总量上限64 MB，图片解码上限5,000万像素；超限单独提示。拼写范围有界，可能漏报或将专有名词误报。复杂 Markdown 的结构提示也可能误报，均应人工核对。

## 助手与手写图片

复用同一份 Skill，无需逐课安装。材料只含本次确认的题目、所选文本及图片副本；图片按文档顺序组织、去除元数据，原图不修改。OCR 仅用于本机隐私检查，不能代替助手直接阅读手写公式。图片检查失败不导出；可以排除图片后重试。

看不清的正负号、下标、指数或缺页应列为不确定，不可猜测。助手建议必须带文本原文与行号，或图片区域和版本。应用核验位置与证据，不代表独立证明数学结论。助手无法查看图片时应标为未检查。

结果仅更新报告，不进入待审核作业、不创建任务、不修改答案、不执行作业代码、不自动提交。文件、题目或选择发生变化后，旧报告仅供参考。等待期间可编辑；已完成批次材料保留30天后清理，未完成批次可在“识别批次与进度”继续处理。

质量问题可以确认后继续；敏感文件、疑似凭据、已有暂存和个人 fork 身份约束始终强制执行。提交记录只保存检查时间、范围、数量及确认状态，不保存报告全文。完整报告和材料包仅留本机，不进入任务备份或公开仓库。手动交给助手前仍应确认材料中没有不希望发送的私人内容。
