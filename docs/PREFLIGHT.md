# 提交前检查

1. 在课程中点“提交作业”，逐项选择文件、关联作业并填写提交说明。
2. 点“下一步：检查”。应用检查拟提交版本：当前 HEAD 加上本次所选变更，不把未选文件当成已提交。
3. 查看问题、依据和建议。修改文件后点“重新检查”；新增图片需要返回文件页自行选择。
4. 可选“在线复核…”直接接回报告，或“Skill 复核…”，逐文件预览文本、题目和图片，排除无关文件或调整顺序。选择适合的助手交接方式（见下文）。
5. 核对问题与未检查范围，勾选确认，再明确点击“提交到个人仓库”。文件变化会要求复查。

## 只检查已写好的作业

1. 在总览、任务或日历选中作业，点详情栏的“检查作业文件…”。
2. 默认选择整个作业文件夹（含子文件夹），也可选择多个文件。有关联课程时从课程目录开始选择，但不要求 GitHub 登录或 Git 仓库。
3. 在“文件范围”预览中搜索、全选或排除文件；隐藏配置、依赖、缓存、构建目录、符号链接及敏感文件列明原因。核对数量后点“开始检查”。
4. 报告显示本机检查覆盖与问题；可“调整范围”回到原有选择。需要核对答案、推导或手写内容时，点“在线复核…”或“Skill 复核…”逐文件预览范围，再选择上传附件或本机助手。
5. 点“完成”关闭报告。不创建提交、不推送、不执行代码，也不改变提交窗口的文件勾选。

| 入口 | 检查的版本 |
| --- | --- |
| 独立“检查作业文件…” | 当前本机文件，包括未提交的修改及当前引用图片 |
| 提交窗口的“下一步：检查” | 当前 HEAD 加上本次选定变更；未选中的已跟踪图片使用 HEAD 版本 |

“检查新作业”是发现老师发布的任务；“检查作业文件…”是检查自己写好的文件。后台读取老师内容不阻止文件检查；Git 写入或退出／更新准备期间会说明暂不可用的原因。已完成任务也可复查。

所选文件夹是读取边界，不读取越界或符号链接目标。越界图片请重新选择共同父目录；远程图片不联网获取。Markdown 引用的图片自动关联、去重；主动排除的图片保持未检查。直接选择文件时以所选文件的共同父目录作为边界，不递归扫描其他文件。

每批最多256个文件（包括引用图片），目录整理最多10,000项。超限要求减少范围，不生成不完整的成功报告。文件在读取时变化会要求复查；报告打开后修改文件会标为过期，重新检查复用未变内容的本机分析缓存。

## 本机能检查什么

- 文本读取、空文件、明显占位、未完成清单、合并冲突标记及疑似未闭合的 Markdown 代码围栏。
- 内联、引用式、HTML 图片，支持中文、空格和相对路径。仓库外路径和符号链接不读取；远程图片不联网获取，标为未验证。
- 图片能否解码、Notebook JSON 的基本结构。Python 在存在 Apple Command Line Tools 解析器时只解析语法；缺少工具或超出限制明确显示未检查，不要求安装。
- 系统英文拼写建议，跳过代码、HTML 标签与属性、公式、链接、文件路径、缩写与单位符号。拼写建议不代表语法错误。中文语义、计算、推导、程序运行与答案正确性不算本机检查通过。

每文件上限5 MB，每批读取总量上限64 MB，图片解码上限5,000万像素；超限单独提示。拼写范围有界，可能漏报或将专有名词误报。复杂 Markdown 的结构提示也可能误报，均应人工核对。

## Gemini 在线复核（测试包）

1. 在“设置 → 作业文件在线复核”或检查报告右上的“在线设置…”配置自己的 Gemini 密钥，阅读服务说明并启用。密钥只存钥匙串，和老师课程识别配置分开。可通过“获取自己的密钥…”打开 AI Studio。使用页面的复制按钮复制完整值；首尾空白会自动清理，密钥内部的空白或不可见字符会被拒绝。新版密钥不再被旧格式字符限制拦截。
2. 使用自己的**未启用计费**项目，点“测试连接”。连接成功只证明密钥和模型可访问，应用无法判断计费状态或剩余免费额度；请自行在 AI Studio 确认。
3. 本机报告完成后点“在线复核…”，在文件清单和详情中核对发送范围、排除无关文件或大型数据，再点“开始在线复核”。无需导出、复制指令或手动导入。
4. 整份项目的文档、代码、数据和图片一起复核，不要求题号或评分标准。缺少题目时不虚构要求，不默认评分或置信度。可选中一条建议点“复核这个疑点”，结合整份项目重新判断。
5. 在线结果在本报告展示，区分明确问题、疑似问题与表达建议。位置、版本、原文证据和图片区域需通过应用校验；校验不等于证明答案正确。图片看不清、事实无法核实时列为未完成。

采用 [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)，只调用 Google 官方 HTTPS。模型没有执行代码、搜索、改文件或提交工具。准备、图片上传、模型等待与证据核验在后台进行，可取消。相同材料、选项和疑点复用本机报告；文件改变后旧报告过期，跨文件一致性需重新核对。超出整体上下文容量时按文档或自然章节处理，项目整体与跨组关系标为未完整检查；单组仍超限时停止并要求缩小范围。

本机每天最多20次生成请求，包含失败与重试，容量分组分别计数；实际免费额度可能更低。限流后停止，不自动切换付费模型、开通计费或发送给其他供应商。使用计费项目仍可能产生费用，这个限制不是金额上限。

图片保持清晰度，去除元数据后通过 [Files API](https://ai.google.dev/gemini-api/docs/files) 上传。完成或取消后尝试删除已知副本；暂时失败时可在1小时内复用仍有效的上传，之后清理。删除失败记录留在本机，重启后重试（停用在线复核后也会继续清理已上传副本），或在“在线设置 → 重试文件清理”立即处理。上传中断而未取得文件标识时，可能无法主动删除未知副本，按供应商保留期限处理。删除副本不等于撤销供应商对材料的数据处理权限。

**免费服务可能使用输入与输出改进产品，并可能由人工审阅。** 请遵守 [Gemini 服务条件](https://ai.google.dev/gemini-api/terms)（包括年龄、地区及用途），不要发送个人敏感信息或保密材料。发送只由你主动发起，不附带其他任务、课程、绝对路径或凭据；本机隐私检查不能保证发现所有私人信息，仍需确认范围。当前测试覆盖模拟接口及原生界面；真实模型质量、网络耗时和账户资格需用自己的项目验证。

## 助手与手写图片

复用同一份 Skill，无需逐课安装。材料只含本次确认的题目、所选文本及图片副本；图片按文档顺序组织、去除元数据，原图不修改。OCR 仅用于本机隐私检查，不能代替助手直接阅读手写公式。图片检查失败不导出；可以排除图片后重试。

### Skill：网页或聊天助手

1. 在材料预览左侧展开文件树并选文件，右侧阅读全文；选中目录可整组包含或排除，部分选中会明确标记。图片支持适合窗口、100%、放大及滚动。文档优先，CSV 只在预览中显示前200行（勾选时导出完整内容），无关数据可以排除。
2. 点“准备材料”，再点“显示附件包并复制指令”。把 `AM-Helper-review.zip` 上传到助手并粘贴指令；应用不会替你发送。
3. 若助手不支持 ZIP，解压后上传其中的 `SKILL.md`、`context.local.json` 和 `image-*.png`。
4. 助手返回 `results.local.json` 后下载，在检查报告点“导入结果…”。批次、文件版本、原文证据及图片区域验证后才接回；重复导入不重复添加。

**仅粘贴 Mac 路径不会让网页聊天获得本机文件访问能力。** 附件方式无需让助手写入 Mac 目录，也不依赖它访问本机。

### 能访问本机文件的助手

在材料预览底部改选“本机助手”，再准备材料、复制本机指令。仅交给已获准访问所选批次目录的助手；结果原子写回后自动接回。没有本机文件访问能力时使用附件方式。

关闭报告后可在“识别批次与进度”重新打开历史检查报告、显示材料与导入结果；历史结果仅适用于导出版本，重新检查当前文件才能确认最新状态。

看不清的正负号、下标、指数或缺页应列为不确定，不可猜测。助手建议必须带文本原文与行号，或图片区域和版本。应用核验位置与证据，不代表独立证明数学结论。助手无法查看图片时应标为未检查。

结果仅更新报告，不进入待审核作业、不创建任务、不修改答案、不执行作业代码、不自动提交。文件、题目或选择发生变化后，旧报告仅供参考。等待期间可编辑；已完成批次材料保留30天后清理，未完成批次可在“识别批次与进度”继续处理。

质量问题可以确认后继续；敏感文件、疑似凭据、已有暂存和个人 fork 身份约束始终强制执行。提交记录只保存检查时间、范围、数量及确认状态，不保存报告全文。完整报告和材料包仅留本机，不进入任务备份或公开仓库。手动交给助手前仍应确认材料中没有不希望发送的私人内容。
