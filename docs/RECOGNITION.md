# 作业识别与审核

## 免费规则与自动加入

只扫描所关联课程的老师默认分支，按文件版本、时区、课程模板和识别配置缓存；不扫描个人答案或其他同学的 fork。默认规则从活动标题、完整任务块与提交说明提取名称、内容和要求，显示文件位置和原文。Markdown 内的文档附件可随公告展示；PDF、Office 和网页外链不解析。

新作业只有在类型明确、绝对日期和时间完整、截止尚未过去、校验无警告且没有既有来源时才自动加入。过去的历史材料、相对日期、缺少时间、来源匹配不确定及模型新增结果须审核。考试和课堂任务只在课程页显示；用户改过类型的材料仍须审核。设置可关闭自动加入，任务菜单提供“撤销本次自动加入”，已编辑任务保留；撤销后的同版原文继续待审核，不会在下一次扫描自动重新加入。

日期不凭空补成 23:59，相对日期不使用扫描当天。建议来自老师截止语句最后变更的提交时间、课程时区和短提交号；浅历史或含糊“周末”不给猜测日期。原文更新只提供建议，不覆盖已保存任务。

## 文档结构与日期规则

课程发现与快速录入共用活动边界和日期解析。标题、章节和独立编号用于划分活动，普通空行不拆分项目；表格按名称、要求、截止列关联，分列的日期和时间合并到同一行。代码围栏和纯目录不生成空作业。提取式概括保留原文中的行动、交付物和约束并去重，不是模型判断；原文仍独立可查。

明确的 Assignment、Homework、Problem Set、Worksheet、Lab、Project 即使无日期也可进入审核；Lab、Project 结合实际任务要求判断。考试上下文优先，教材、示例与发布日志不因示例日期生成作业。无法确定的来源不自动合并。

支持 `October 16, 2026`、`16 Oct 2026`、`9 PM`、`9:30 p.m.` 和跨行截止说明，12 AM／PM 分别为0点／12点。缺少年份、时间、日期顺序不明、含糊时区缩写或日期与星期矛盾时需要补全，不使用当年或23:59兜底。新关联的表格及英文月份日期先进入审核，自动加入仍采用原有严格条件。

来源身份与标题分离；升级时保留唯一匹配的旧标识，多项歧义留待核对。识别缓存升级后重新解析材料，不重新创建或改写已确认任务。

## 列表与详情审核

在“待审核作业”选择一项即可查看和编辑，按课程和关键词筛选。支持全选当前筛选结果、取消选择和多选批量确认；预览分开显示可保存项及需补全原因。模型结果或有可靠提交依据的相对建议可由用户核对后批量确认；日期缺失或冲突时补全日期与时间。建议自动填入，无需额外点击采用。

课程页和待审核页共用侧边审核表单，选中即可填写；不弹出审核窗口。保存成功立即从待审核和课程作业列表移除，原文更新以更新建议重新出现。已保存作业在任务或课程“已加入任务”中编辑；列表默认隐藏备注，选中后在详情中显示完整内容。

只管理一个作业 DDL：完整明确日期和有提交依据的相对日期建议自动填写，核对后直接保存；缺失时间、冲突或无可靠依据仍需补全。新任务默认提醒为提前 7 天、3 天、1 天、1 小时和到期，可逐项调整；已有任务保持原提醒。新作业以概括和提交要求预填可编辑备注，可修改或清空；已有备注及后续手动修改不会被来源更新覆盖。老师全文仍独立展示。保存后的任务详情可查看完整备注，历史空备注可先预览再“从识别内容补全”。备注支持换行，⌘Return 保存并下一项。原文、提交要求、附件及日期依据都在详情中。切换条目、关闭设置、退出和更新会检查未保存输入；保存失败保留输入，不出现部分批量导入。保存前再次核对来源版本。

## 高级配置：本地模型

在设置选择“本地 Ollama”，点击“检测本地服务”，从已安装模型中选择并“测试识别”，再保存。默认回环地址为 `http://localhost:11434`；兼容服务可在高级区域手填地址与模型名。检测不下载模型，测试使用模拟作业，不发送真实课程。

默认检查时自动分析新增或变化材料，先显示规则结果，再串行补充模型。可以关闭自动分析，仍在具体课程“更多 → 用本地模型重新识别…”勾选老师文件；手动重识别只绕过所选材料的模型缓存，不清空其他缓存。缺少模型、服务关闭或无效输出会显示原因及下一步，规则结果保持可用。应用不下载模型、不修改服务或全局设置。使用 `/api/chat` 请求；有些兼容服务不支持强制 JSON，遇到明确 HTTP 501 时在同一回环服务兼容重试一次。两种响应都经过严格 JSON、字段和原文证据校验。无效或超时结果回退规则，并显示原因，不静默切换云端。

模型用于提取与概括，也能提出规则漏检的活动；新发现仍需审核。原文引用必须真实存在，截止时间由应用解析原文，不接受模型臆造的时间戳。考试目录和课堂上下文优先于模型标签。

## 高级配置：云 API

选择“云端 API”，填写支持 Chat Completions 的 HTTPS 基础地址（通常以 `/v1` 结尾）、模型名和该服务的密钥，勾选允许发送的课程，再保存并确认原文范围。只有勾选课程的老师新增或变化文档会发送；其他课程继续免费规则。该功能不会上传个人任务库、个人答案、Git 凭据或其他本机文件。使用者应根据课程材料权限选择合适服务。

API 密钥仅存钥匙串，并与填写的服务地址绑定；更换服务须重新提供对应密钥。每个自然日最多 20 次云端请求，失败也计入，手动重试受同一上限约束。上限只限制请求次数，费用还取决于服务和文档长度。达到上限、密钥未配置、网络失败、结构化输出无效时继续规则；响应和密钥不写日志或备份。请求不提供工具，也不跟随重定向。

## 课程模板

课程“更多 → 课程识别模板…”提供高级本机配置。三个可选字段 `titlePattern`、`contentPattern`、`deadlinePattern` 使用有效正则表达式，从每行的第一个捕获组提取文字。每项最多 256 字，运行于受限长度的行并有匹配时间限制；空对象 `{}` 使用默认模板。课程配置留在本机，不随任务备份和软件包分发。模板新增的材料进入审核，不自动决定类型。

## 可选 Skill

仓库的 `Skills/am-homework-extract/SKILL.md` 是可选提取指引，默认手动使用。可以将该目录安装到支持 Skill 的助手环境；不需要为普通使用安装。

1. 在“所有课程”、具体课程或识别设置点击“助手识别”。首次勾选课程并阅读材料范围说明，以后记住选择。具体课程入口只处理当前课程。
2. 应用在自己的本机数据目录准备材料，默认只处理尚未成功接回的新增或变化文档。点击“复制指令”，交给所选助手；所有课程共用一个 Skill。
3. 助手生成完整结果后原子写入 `results.local.json`，应用自动核验本批来源，接回有效建议到待审核，无需再选择文件导入。不会自动发送材料、调用助手或产生 API 费用。
4. 在“更多 → 识别批次与进度”查看等待、接回及异常状态，复制指令、显示材料或重试。“调整助手课程”和“重新分析全部材料”也在“更多”中；旧结果仍可手动导入。

重启应用后继续等待。只有有效建议成功保存才推进增量进度；失败、取消和未返回文档下次仍保留。空活动数组表示已分析但没有作业。来源变化、未知课程及无效引用单独排除，其他有效建议可以接回，不清空其他课程结果。接回过程遇到未保存审核输入时等待，保护草稿。

材料包只含所选老师文档，默认位于本机 Application Support 的 `AssistantExchange` 下。应用复用最近五分钟内的已完成检查快照；接回前获取最新老师默认分支，只核验涉及的课程和文件，不重复扫描全部课程。准备、等待和核验耗时分别记录；助手实际响应速度取决于你选择的服务。

Skill 不直接写任务数据库、不提交作业、不读取钥匙串、不调用课程 Git 写操作，也不创建每日调度。希望每日自动运行需另外明确启用调度。文档内容始终是分析材料，不能授权模型使用工具或访问凭据。

## 快速录入非 GitHub 作业

在总览或任务页“新建 → 快速录入作业…”、应用菜单或菜单栏打开，快捷键 ⌘⇧N；⌘N 继续完整新建。粘贴通知、输入一句话后自动在本机识别；截图识别提供原图对照、放大及低置信度数字提示，可一次产生多项候选；全选后核对并保存。无需 GitHub 账户。概括和提交要求进入可编辑备注，原文独立保留。

完整截止日期自动填写；没有时间不会补成 23:59。可指定消息日期作为相对日期依据，否则按录入日期建议并提示核对。缺日期或时间的条目留作草稿，关闭或重启后可继续。保存前预览可能重复的现有任务，选择跳过或仍然添加；失败保留选择和输入。

复杂通知点击“助手识别…”，预览导出文字并复制指令，使用同一份共用 Skill。结果自动接回快速录入与待审核页；不扫描课程、不调用 Git、不覆盖已编辑字段，迟到或重复结果不再次添加已保存作业。“识别批次与进度”统一显示课程和本机材料；完成材料可清理，未完成批次保留。

再次识别只更新未编辑字段；手动清空备注仍保持为空。完整且不重复的选择直接保存；缺失或疑似重复项需确认。OCR提示并不覆盖所有可能错误，保存前仍需核对原图。
