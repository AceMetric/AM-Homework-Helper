# AM Helper 1.13.0

版本 1.13.0／构建32，macOS 13+、Apple 芯片，未经 Apple 公证。

## 界面与操作

- 修复任务输入框圆角失效；备注使用圆角容器，日期和时间合并为原生控件，保存操作固定在窗口底部。
- 任务编辑可点击窗口内灰色区域退出；有未保存修改时保留保存、放弃及继续编辑的选择。
- 扩大任务完成与更多操作的点击范围，保持图标正常尺寸；支持原生多选和空格切换完成状态。
- 日历使用可辨底色区分周末，假期与补班标记放在日期格底部，任务行保持对齐。
- 精简课程审核表单及操作栏，设置直接显示选项；其他页面的折叠标题整行可点击，移除重复操作提示。

## 周期任务与日历

- 支持固定日历及完成后重复，日／周／月／年间隔、每周多个星期、结束日期或次数，以及后续日期预览。
- 可按任务选择保持日期、跳过休息日、提前或顺延；支持仅修改本次、本次及以后、停止重复和补建漏过项。
- 提供离线可用的 2026 年中国大陆放假调休数据及本机学校安排覆盖。未收录年份明确提示，不猜测调休。
- 旧任务数据继续沿用；新备份包含周期系列和日历覆盖，同时兼容旧备份。

## 提交记录与 AI 流程

- 自动发现已关联个人仓库目标分支的外部 Git 提交，区分本地、已核验远端和待核验状态。可关联作业，不自动完成任务或推送。
- 后台课程检查默认保留免费规则；云端增强由用户主动选择老师材料并确认范围，结果接入同一审核列表。
- 更新识别及复核提示词，先核对活动边界再关联日期；整份项目复核保留跨文件关系，区分明确问题、疑点和表达建议，并列出未完成内容。

本机回归使用模拟数据、临时仓库和模拟在线响应；不代表真实模型质量或服务可用性已全面验证。本版未重新调用真实在线模型。旧系统实际外观、辅助功能及正式下载安装仍需使用者验证。

保留个人仓库推送核验、钥匙串凭据和更新签名；不自动执行作业代码、修改答案、提交或启用付费服务。
