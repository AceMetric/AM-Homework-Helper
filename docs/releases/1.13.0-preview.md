尚未发布正式安装更新；实际外观待用户截图核对，未经 Apple 公证。

- 修正普通边框覆盖圆角凹槽的问题；任务编辑使用可调整布局、原生日期时间控件和固定底部操作。
- 根据实际预览反馈修正备注的方形边框和底部按钮边距；日历使用应用强调色标记假期，中性背景区分周末和补班，窄窗口保留可读名称。
- 扩大任务完成与更多操作的点击范围，支持原生多选及空格操作；课程审核收紧表单宽度，分开日期与提醒，减少顶部操作行。
- 更多操作图标保持正常尺寸；普通周末仅用可辨底色区分，任务与工作日对齐。设置直接显示选项，其他折叠标题整行可点击。
- 假期与补班标记放在日期格底部，所有任务行保持对齐；任务编辑支持点击灰色区域退出并保护未保存输入，移除审核常驻提示条。
- 新增固定日历及完成后重复、期限／次数、休息日避让、周期预览及本机日期覆盖；提供经政府通知核对的 2026 年中国大陆放假调休数据。
- 自动发现已关联仓库的外部 Git 提交，区分本地与已核验推送；关联作业不改变完成状态，也不自动推送。
- 课程云端增强改为主动预览所选老师材料后发送；版本化提示词和活动证据校验防止邻近作业串日期。
- 在线复核继续检查整份项目，未完成内容直接列入报告；疑似问题及表达建议不作为确定错误。

测试使用改写样例、隔离数据及临时仓库。未重新调用真实在线模型；模型质量、所有旧系统的实际外观及正式下载安装仍待验证。
