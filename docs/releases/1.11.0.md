# AM Helper 1.11.0

版本1.11.0／构建28，macOS13+、Apple芯片，未经Apple公证。

- 文件检查改为独立可调整、可最大化的工作窗口，记住尺寸和范围分栏。搜索文件树、折叠排除项，右侧预览Markdown／公式、源码和图片；返回范围保留选择，关闭只收起，工具栏可恢复。
- 固定离线markdown-it 15.0.2、MathJax 4.1.3、DOMPurify 3.4.17及对应SVG字体，校验依赖并保留许可证。捕获公式解析错误、兼容疑点和宽公式提示，按行定位；超时、超限和不可用单列未完成。本机、公式与在线覆盖分别显示，GitHub风格不承诺在线页面逐像素相同。
- 文件／图片进度、等待阶段和耗时更明显；主工具栏与后台任务面板可查看跨页面操作，Skill、OCR、上传清理、备份与更新也有相应状态。未知总量不制造百分比，Git写入不强制中止。
- 修复外观改变时重建页面、日历混合颜色停留在旧外观及网页配色的延迟覆盖。保留草稿、选择、滚动和焦点。macOS26+导航层使用Apple原生Regular Liquid Glass，旧系统使用原生视觉效果回退；正文保持清晰底色。
- 检查取消后立即重试使用独立缓存，迟到回调不覆盖新报告。历史检查也使用工作窗口，主窗口仍可编辑无关任务；文件变化后报告继续标为过期，提交安全约束保持。

已完成的验证与未验证范围见仓库验证说明。此前真实合成文本、单图生成成功，只证明测试时账户可生成；37文件／19图真实在线测试因钥匙串授权未继续，按用户选择保留待验证，未向Google发送这批材料。持续503不能由本机界面改动保证消失，在线失败仍明确显示未完成，不宣称答案一定正确。

macOS13实机、全局系统外观实际切换、同学可用性及正式下载安装仍待验证。正式下载安装由使用者完成，已有任务、课程和凭据兼容标识保持。
