# AM Helper 1.12.0

版本 1.12.0／构建 29，macOS 13+、Apple 芯片，未经 Apple 公证。

- 主窗口改为系统分栏侧栏、原生工具栏与搜索。macOS 26+由系统提供 Liquid Glass，主要操作使用官方玻璃按钮；正文、文档、公式和报告保持清晰底色。旧系统使用标准控件。
- 总览与任务共用原生任务列表，审核使用系统列表选中态；课程分段、表单、设置和配置引导统一操作层级与配色。中间分段使用系统胶囊选中样式，界面不再手绘选中块。
- “＋”直接快速录入，完整新建保留 ⌘N。搜索点外部或按 Escape 退出，内容保留，⌘F继续搜索。常驻的检查和沙漏图标移入“窗口”菜单。
- 提交页及检查报告使用可调整分栏。窗口扩大时列表与预览一起扩展，操作固定在底部；展开差异预览支持完整阅读、横向滚动与选择复制。预览脱敏与诊断日志截断分别处理，已有大小限制仍保留明确说明。
- 有后台操作时显示目标、阶段、进度和详情入口；空闲时收起。进行中的记录优先，已完成记录默认折叠，失败详情可滚动、复制。在线设置内容可滚动，保存和取消固定可见。
- 正式构建要求 SDK 26+，构建缓存包含 SDK 信息；外观更新继续保留草稿、选择与有效滚动位置。
- 修复主题刷新给菜单栏图标和系统弹出层铺上不透明底色的问题，保留系统管理的背景与材质。

任务数据库、课程、备注、计划、子任务、钥匙串及更新公钥兼容标识保持。文件检查不会执行作业代码或隐式提交，推送仍核验个人 fork。

原生控件样例已由使用者确认；功能与布局验证及其限制见仓库验证说明。macOS 13–26 实机、全部推广页面的实际系统外观切换与 VoiceOver 仍待验证。正式下载安装由使用者验证。

本次更新不代表 Gemini 服务故障或模型质量已全部解决；在线失败仍显示未完成。此前大型多图真实在线测试按使用者选择保留待验证，未继续请求密钥授权。
