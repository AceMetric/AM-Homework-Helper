# AM Helper 1.17.0

构建 46 · 2026-10-30

- 课程管理集中显示老师仓库、个人仓库与本地目录。可从课程目录或父目录匹配已有仓库，核对身份后关联。
- 从作业进入提交时优先显示已确认归属的改动；其他改动可随时展开，刷新保留勾选和输入。提交说明自动概括所选文件，手动修改后不再覆盖。
- 支持向已确认作业目录拖入文件、粘贴图片及复制相对 Markdown 图片引用；同名文件先改名，不覆盖原文件。可在外部编辑器、Finder 或终端打开明确目标。
- 单一渲染报告增加要求核对表，区分已核对、发现问题、缺少材料与未检查，并可打开对应依据。
- 新增“同学作业”：按作业范围核验可访问 fork 的作答改动，选择同学和文件后读取固定版本的 Markdown、图片或 PDF。普通浏览不调用模型，不修改任何同学仓库。
- 新增本机“评分参考排名”：优先采用核对后的老师分数；老师只有评语时，可按确认的统一百分制标准，结合题目、完整作答和评语生成 LLM 参考分。明确标注评分来源，支持混合来源筛选与同分并列。
- 评分前核对材料、模型及请求上限，默认最多4次。缺题、缺图、来源冲突、输出无效、取消或保存失败不生成可排名的完整分数。已有完整结果独立保存，材料或评价变化后需重新核验。
- 任务详情新增实际用时：开始、暂停、结束、补录、修改、删除及撤销。全应用同时运行一个计时器，睡眠、退出和完成任务时暂停，重启不补计停机时间。
- 修复作业中的“小测／quiz”误判为考试；实际考试不再进入识别，也不调用模型。规则、模型和已有完整缓存统一校正来源归属，重新识别按所选来源替换旧机器候选，减少重复；已有任务与用户修改保留。
- 备份兼容升级，加入实际用时和评分设置，继续接受旧备份；不包含凭据或同学作答预览缓存。

本地评分使用用户配置的本地模型；云端评分使用用户自己的服务与密钥，确认发送范围后才请求。合成材料验证本地模型与协议，不代表对所有课程评分准确性的保证。

当前构建为 Apple Silicon 版本，使用临时签名，未经 Apple 公证。
