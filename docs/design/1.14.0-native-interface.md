# 1.14.0 原生界面与交互统一

目标版本：1.14.0／构建36。正式发布以前须确认独立模拟预览的实际窗口。

## 一致的操作

- 所有“＋”、新建菜单和 ⌘N 使用手动新建表单；日期与课程上下文先填入，再建立修改基线。
- 文字／截图录入保留 ⌘⇧N，使用相同字段组件；从新建窗口进入时保留手动草稿。
- 现有任务在右侧直接编辑。空间不足时迁移同一编辑器到弹窗，保留草稿和输入位置；宽度恢复后迁回。
- 保存、取消始终可见；提醒、重复、优先级以摘要行进入详情。计划与子任务保留独立入口。
- 新建、编辑、审核、识别候选共享 TaskFields；任务持久化、来源核验和周期规则仍通过既有控制器处理。

## 页面与反馈

- 页面标题区不随消息伸缩。课程主要操作、搜索和材料筛选由系统工具栏承载，溢出保留可操作菜单。
- 活动入口复用后台调度器。消息包含作用域、身份、内容版本、严重程度、动作与关闭状态；仅限当前会话。
- 普通成功以短暂状态图标反馈；展开活动可查看记录。关闭消息不会取消任务、清除错误依据或越过安全检查。
- 已关闭的相同消息不因刷新复活；编辑错误贴近字段，来源改变与保存失败保留输入。
- 设置采用类别导航；提交窗口明确展示选择文件、检查、提交三个步骤。
- 内容区采用系统普通控件与语义颜色，移除全局大号、胶囊和玻璃覆盖；导航分段仍由公开系统 API 绘制。

## 文案清单与处理规则

| 位置／内容 | 处理 |
| --- | --- |
| 任务表单字段、提醒与周期当前值 | 保留、统一命名 |
| 标题区保存成功与检查进度 | 移至活动，正文不占位 |
| 日期字段下重复的日期和剩余时间 | 删除重复内容；保留必要日期依据与逾期后果 |
| 新建入口对识别方式的说明 | 收为“从文字或截图录入…”次要操作 |
| 备注修改说明与无内容提示 | 仅保留“备注”及空状态结果 |
| 常驻教程与功能介绍 | 归入“开始使用” |
| 字段错误、恢复入口、权限与来源变化 | 保留并提供对应动作 |
| 发送范围、费用、提交目标与不可撤销后果 | 在对应操作或确认中保留 |
| 用户备注、老师原文、来源证据与报告正文 | 完整保留 |

## 数据与兼容边界

- 不迁移任务数据库，不更换钥匙串身份或更新签名。
- 继续使用真实修改基线；打开窗口、布局、主题与后台状态不等于修改。
- 保存基于最新任务合并用户编辑字段，保留其他位置的完成状态等变更；同字段冲突时拒绝覆盖并保留草稿。
- 已修改草稿继续暂缓自动完成；只选中但未修改的任务允许后台完成并刷新。
- 删除、周期、提醒、增量检查、提交安全和退出协调仍沿用原有存储与调度规则。

## 验收

自动检查覆盖入口一致、消息关闭／去重、窗口缩放、共享字段、真实保存目标、来源日期确认、连续审核、主题切换与光标保持、后台操作、提醒、周期、提交和更新退出。

自动检查和控件属性不代替外观验收。使用隔离模拟预览，由用户检查浅深外观、失活窗口、辅助显示设置、最小尺寸与工具栏溢出。不捕获屏幕，不读取真实课程或在线模型凭据。旧系统实机和辅助功能体验保留实际核对。
