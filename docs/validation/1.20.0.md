# 1.20.0 验收边界与模型样例

本版使用独立 ChatGPT 授权进行真实模型测试，公开样例均为合成材料。普通回归使用模拟认证和传输，不需要真实账号，也不发送课程内容。

## 真实模型抽查

- GPT-6 Luna / low：12组开发材料及4组保留材料；另外4组提炼要求，检查交付项、条件与原文引用。
- GPT-6.1 Terra / medium：正确函数与文字说明、错误的单词反转、数学展开缺项、CSV与报告均值矛盾。四组结果均与人工预期一致，文本依据通过本机位置及版本核验；未执行学生代码。
- 框架已提供的功能不生成学生交付项；跳题条件保持关联；PNG推荐尺寸没有升级为强制要求。
- 共享日期样例中模型未直接返回截止引用，本机规则为两组保留日期文字并要求补全时刻，没有虚构具体截止时间。

相同12组识别材料中，精简前输入共13,981 token，精简后6,049 token，减少56.7%。这是本轮提示词内部对照，不能代替与旧正式版在相同覆盖范围下的完整对照。ChatGPT套餐用量不按API价格折算金额。

这些样例不能证明所有学科和材料的正确率。规则结果、源文本引用和模型建议仍需分别展示，缺材料、中断和错误引用不能当成检查通过。

## 自动回归与人工验收

覆盖列表快照缩短和迟到回调、嵌入提交草稿与刷新、老师版本定位、原文引用、官方登录回调与令牌轮换、小时计数、应用级并发排队、流中断及官方额度错误。冷启动的钥匙串读取在后台进行。

可见窗口点击验收与静默组件测试分开记录。几何坐标和断言不能替代对系统材质、字体与完整布局的视觉审查。验收不捕获屏幕，安装升级使用隔离副本，真实课程仓库保持只读。

手动重现模型抽查：`AM_LIVE_MODEL_QA=1 zsh verify-live-models.sh`。脚本只打开隔离窗口，用户登录并点击运行后才发送合成材料；请求次数包含失败及重试。历史成功项复用，避免重复发送。

### 可见验收程序修正

布局验收程序沿用真实应用启动通知，持有应用代理；不再提前结束启动后手动调用代理。工具栏分段由系统工具栏分组持有独立表示，避免将正文控件反复移入不同布局引擎。点击断言后继续运行事件循环，覆盖延迟布局。

验收程序从应用包加载完整 Renderer 资源，并验证实际 Markdown 标题与列表；窗口启动不依赖仓库工作目录。WebKit 验证从运行循环启动，避免将整轮验证放在主队列块内、阻塞网页回调。演示作业也进入同一任务投影，刷新和跨页浏览不替换成无关样例。

可见复验：`AM_UI_FOREGROUND=1 zsh verify-assignment-window.sh`；保留窗口供人工查看：额外设置 `AM_UI_HOLD_REVIEW=1`。不捕获图像、不访问正式任务数据、不发送在线请求。

最终可见复验覆盖了返回按钮在窗口标题显示／隐藏时的实际左侧坐标、三标签固定位置、紧凑居中选择器、实际 Markdown 渲染、最小窗口收栏，以及刷新后同一任务投影仍保留三张卡片。用户复看后确认“看起来没有大问题了”。录入弹窗另验证父窗口尺寸限制和底部保存按钮的实际包含关系；短窗口的中间内容可滚动。
