# 周期安排与中国大陆日历

本功能随 1.13.0 开发预览提供，正式发布前仍需核对实际窗口。原有任务不迁移、不重新创建。

## 设置重复

编辑自己的任务，在“重复”中选择“不重复”“按固定日历”或“完成后重复”。设置天／周／月／年间隔、每周的星期、截至日期或总次数；保存前查看示例日期。

- 固定日历以初始日期为基准。月底不存在同一天时使用当月最后一天，后续继续沿用原日期；完成时间不改变后续周期。
- 完成后重复以实际完成日期计算下一次，保留所设时刻。撤销完成保留已生成的后续项，不重复生成。
- 默认准备未来 90 天，浏览更远日历时按所查看的范围补齐。“文件 → 补建漏过的周期任务…”可选择过去范围；不补发过去提醒。
- 已有发生项可选择“仅修改本次”或“修改本次及以后”。后者保留已完成及手动修改的历史；选择“不重复”并修改本次及以后可停止重复。
- 删除本次可跳过该次；已删除的发生项不会因再次检查而复活。
- 老师原作业的截止时间保持不变。任务菜单“另建周期安排…”创建个人安排，不复制老师来源身份。

## 周末、假期与调休

默认只标记日期，保持任务日期。每个周期任务可选择跳过、提前或顺延；补班日属于工作日。重复的名义日期仍有独立身份，多项顺延到同一天也不会被错误合并。

2026 年数据依据[国务院办公厅通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，并按[政府转载](https://www.haishu.gov.cn/col/col1229825334/art/2025/art_5fc4718a8a495bac1b9a2e2f231be305.html)核对。数据随应用提供，离线可用；当前未收录其他年份。

未收录年份会明确标记。使用假期避让时需要确认该年份暂时仅按周末处理；不猜测调休。“设置 → 日历与假期”或“文件 → 休息日／工作日设置…”可添加学校日期覆盖，记录名称与依据，也可恢复官方安排。覆盖不批量改写已有任务。

周期日历默认使用 Asia/Shanghai。备份 v3 包含任务、提交记录、周期规则及本机日期覆盖，同时继续接受旧数组和 v2 备份；凭据不进入备份。
